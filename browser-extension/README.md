# 暮城笔记 - 网页剪藏浏览器扩展

将网页内容快速保存到暮城笔记。

## 功能

- 一键保存网页文章到笔记
- 智能提取文章内容（使用 Readability 算法）
- 支持选择保存到指定文件夹
- 支持右键菜单快速剪藏选中文本
- 支持 Chrome、Edge、Firefox 等主流浏览器

## 安装方法

### Chrome / Edge

1. 打开浏览器扩展管理页面
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `browser-extension` 文件夹

### Firefox

1. 打开 `about:debugging#/runtime/this-firefox`
2. 点击「临时载入附加组件」
3. 选择 `browser-extension/manifest.json` 文件

## 使用方法

1. 确保暮城笔记桌面应用已启动
2. 在浏览器中打开想要保存的网页
3. 点击浏览器工具栏中的暮城笔记图标
4. 编辑标题、选择文件夹
5. 点击「保存到笔记」
6. 在暮城笔记应用中确认保存

## 右键菜单

- 选中网页中的文本后，右键选择「保存选中内容到暮城笔记」
- 在网页空白处右键，选择「保存整个页面到暮城笔记」

## 技术说明

- 扩展通过 HTTP 请求与暮城笔记桌面应用通信
- 本地服务地址: `http://127.0.0.1:27183`
- 使用 Readability.js 算法提取网页主要内容

## 图标

请将应用图标复制到 `icons` 文件夹：
- `icon16.png` - 16x16 像素
- `icon32.png` - 32x32 像素
- `icon48.png` - 48x48 像素
- `icon128.png` - 128x128 像素

可以使用项目根目录 `icons` 文件夹中的图标，调整大小后使用。

## 故障排除

### 显示「未连接」

1. 确保暮城笔记桌面应用已启动
2. 检查应用是否正常运行
3. 尝试重启应用

### 无法提取内容

某些网页可能使用了特殊的内容加载方式，导致无法正确提取。可以尝试：
1. 选中想要保存的文本
2. 使用右键菜单「保存选中内容到暮城笔记」
