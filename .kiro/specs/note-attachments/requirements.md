# 笔记附件功能需求文档

## 概述

当前笔记编辑器仅支持纯 Markdown 文本编辑，需要扩展支持添加各种类型的附件文件，如文档（PDF、Word、Excel等）、压缩包、音频、视频、图片等。

## 用户故事

### 用户故事 1：添加附件

**作为** 笔记用户  
**我想要** 在笔记中添加各种类型的文件附件  
**以便于** 将相关文档、资料与笔记内容关联保存

**验收标准：**
- 1.1 编辑器工具栏显示「添加附件」按钮
- 1.2 点击按钮打开系统文件选择器
- 1.3 支持选择任意类型的文件
- 1.4 文件大小限制为 50MB
- 1.5 添加成功后在笔记中插入附件引用

### 用户故事 2：附件显示

**作为** 笔记用户  
**我想要** 清晰地看到笔记中的附件信息  
**以便于** 快速识别和管理附件

**验收标准：**
- 2.1 附件以卡片形式显示在预览模式中
- 2.2 卡片显示文件图标（根据文件类型）
- 2.3 卡片显示文件名
- 2.4 卡片显示文件大小
- 2.5 编辑模式显示 Markdown 格式的附件引用

### 用户故事 3：附件操作

**作为** 笔记用户  
**我想要** 对附件进行常用操作  
**以便于** 方便地使用和管理附件

**验收标准：**
- 3.1 点击附件卡片可以打开/预览文件
- 3.2 提供「另存为」功能导出附件
- 3.3 提供「删除」功能移除附件
- 3.4 删除前显示确认对话框

### 用户故事 4：拖拽添加

**作为** 笔记用户  
**我想要** 通过拖拽方式添加附件  
**以便于** 更快捷地添加文件

**验收标准：**
- 4.1 支持从系统文件管理器拖拽文件到编辑器
- 4.2 拖拽时显示放置提示区域
- 4.3 图片文件自动以图片形式插入
- 4.4 其他文件以附件引用形式插入

### 用户故事 5：附件同步

**作为** 多设备用户  
**我想要** 附件能够在设备间同步  
**以便于** 在任何设备上访问附件

**验收标准：**
- 5.1 附件数据通过现有 Resource 机制存储
- 5.2 附件随笔记一起同步到服务器
- 5.3 同步时显示附件上传/下载进度

### 用户故事 6：移动端支持

**作为** 移动端用户  
**我想要** 在手机上也能添加和查看附件  
**以便于** 随时随地管理笔记附件

**验收标准：**
- 6.1 Android 端支持从相册/文件管理器选择文件
- 6.2 Android 端正确显示附件卡片
- 6.3 Android 端支持打开/分享附件
- 6.4 Android 端支持删除附件

## 技术约束

- 单个附件文件大小限制：50MB
- 单个笔记附件总大小限制：200MB
- 支持的文件类型：所有类型（不做限制）
- 附件存储：文件存储在本地 resources 目录，元数据存储在数据库
- 附件在 Markdown 中以自定义语法引用：`[attachment:resourceId](filename)`

## 文件类型图标映射

| 文件类型 | 图标 |
|---------|------|
| PDF | FilePdfOutlined |
| Word (.doc, .docx) | FileWordOutlined |
| Excel (.xls, .xlsx) | FileExcelOutlined |
| PowerPoint (.ppt, .pptx) | FilePptOutlined |
| 压缩包 (.zip, .rar, .7z) | FileZipOutlined |
| 文本 (.txt, .md) | FileTextOutlined |
| 音频 (.mp3, .wav, .ogg) | SoundOutlined |
| 视频 (.mp4, .avi, .mov) | VideoCameraOutlined |
| 图片 (.png, .jpg, .gif) | PictureOutlined |
| 其他 | FileOutlined |
